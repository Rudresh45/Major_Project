# 🚗 Carpooling Website

A web app that helps drivers and passengers connect to share rides, reduce travel costs, and lower emissions.

---

## 🌐 Features

- User sign-up/login (Driver & Passenger)
- Post, browse, and request rides
- Google Maps integration (for routes)
- Booking & ride status updates
- Mobile-responsive design
